# Poker Night

Poker with friends: chips, bank, loans, settlement, two game types, real or online cards, chat with voice notes.

- Live site: `index.html` (built file, served by GitHub Pages)
- Source: `source/src` (engine.js = rules, store.js = storage, app.js = screens)
- Rebuild: `cd source && python3 build.py` → copy `dist/index.html` to the repo root
